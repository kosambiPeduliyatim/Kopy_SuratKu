Informasi Penyimpanan Lokal & Pemeliharaan

Pusat Bantuan & Panduan Pengguna

Petunjuk lengkap penggunaan aplikasi KOPY SuratKu dengan bahasa yang sederhana dan mudah dipahami.

Keterangan & Batasan Hukum Penting:
1. KOPY SuratKu adalah alat bantu penyusunan draf surat dan dokumen administrasi secara mandiri.
2. Aplikasi ini tidak menerbitkan dokumen resmi negara dan tidak otomatis menjadikan setiap surat sah secara hukum tanpa tanda tangan, stempel, atau verifikasi pejabat berwenang.
3. Khusus surat keterangan kependudukan (seperti Domisili, SKU, SKTM, Pengantar Pindah), draf dari aplikasi harus diperiksa dan disahkan oleh Ketua RT/RW, Kelurahan/Desa, atau instansi terkait.
4. Gambar tanda tangan yang ditambahkan pada aplikasi hanyalah elemen visual dan bukan tanda tangan elektronik tersertifikasi (BSrE/PSrE).

1. Cara Memilih Template Surat

Buka menu Buat Surat atau Semua Template. Anda dapat mengetik kata kunci pada kolom pencarian (contoh: "undangan rapat", "permohonan donasi", atau "tagihan") maupun memilih salah satu dari 6 kategori (A sampai F). Tekan tombol Gunakan Template untuk mulai mengisi formulir.

2. Cara Mengisi Formulir Otomatis

Setiap jenis surat menampilkan kolom isian yang disesuaikan dengan kebutuhannya saja. Pilih Profil Organisasi di bagian atas formulir agar kop surat, kota, dan nama penandatangan terisi otomatis. Kolom bertanda bintang merah (*) wajib diisi sebelum melanjutkan.

3. Cara Mengedit Isi Surat pada Lembar A4

Setelah menekan Lanjut ke Preview & Editor Surat, dokumen tampil dalam bentuk lembar kertas A4. Gunakan Panel Edit Dokumen di samping/atas untuk mengubah judul, nomor, tanggal, penerima, gaya bahasa, maupun menambah, menghapus, dan menggeser urutan paragraf.

4. Cara Menyimpan Identitas Organisasi

Masuk ke menu Organisasi Saya. Anda dapat menyimpan banyak profil sekaligus (misalnya profil RT/RW, Karang Taruna, Yayasan KOPY, Sekolah, dan Usaha UMKM). Anda juga bisa mengunggah logo dari galeri HP dan mengatur profil mana yang aktif.

5. Cara Membuat & Mengatur Kop Surat

Buka menu Kop Surat. Pilih tata letak logo (Logo Kiri, Logo Tengah, atau Tanpa Logo), atur ukuran logo dan jenis garis pembatas bawah kop, lalu lihat hasilnya secara langsung sebelum menekan Simpan Desain Kop Surat.

6. Cara Membuat Nomor Surat Otomatis

Nomor surat dibuat otomatis sesuai pola organisasi (contoh: 001/KOPY/SOSIAL/XI/2026). Anda dapat mengubah format pola, bulan Romawi, dan aturan reset tahunan/bulanan di menu Pengaturan, atau mengedit nomornya secara manual pada formulir. Jika nomor yang sama pernah dipakai pada organisasi tersebut, aplikasi akan memberikan peringatan.

7. Cara Memilih & Menyimpan Penandatangan

Pada menu Organisasi Saya bagian bawah, simpan nama dan jabatan pengurus yang sering menandatangani surat. Saat membuat surat, cukup pilih nama penandatangan dari daftar dropdown.

8. Cara Menyimpan Dokumen ke Arsip

Pada tahap Preview & Editor, tekan tombol Simpan ke Arsip. Dokumen akan tersimpan di menu Arsip Dokumen sehingga kapan saja dapat dibuka kembali, diduplikasi, ditandai favorit, atau diedit ulang.

9. Cara Mencetak Surat & Menyimpan sebagai PDF di HP Android

  1. Pada halaman Editor atau Arsip, tekan tombol Cetak / Simpan PDF.
  2. Dialog cetak browser akan terbuka dengan tampilan bersih kertas A4 tanpa tombol menu aplikasi.
  3. Pada pilihan printer di bagian atas layar HP Android, pilih Simpan sebagai PDF (Save as PDF).
  4. Pastikan ukuran kertas diatur ke ISO A4 dan skala 100%, lalu tekan ikon unduh PDF untuk menyimpannya ke memori HP Anda.

10. Cara Melakukan Backup & Mengembalikan Data

Buka menu Pengaturan bagian Ekspor & Impor Cadangan Data. Tekan Ekspor Seluruh Data untuk mengunduh file .json. Untuk memulihkan data di perangkat baru, pilih file .json tersebut lalu pilih Gabungkan Data atau Timpa Data.

11. Cara Menggunakan Aplikasi Secara Offline

Saat KOPY SuratKu dibuka melalui alamat web HTTPS (seperti GitHub Pages) atau http://localhost, Service Worker akan menyimpan seluruh file aplikasi secara otomatis ke perangkat Anda. Setelah itu, aplikasi tetap dapat dibuka, digunakan membuat surat, dan mencetak meskipun paket data/Wi-Fi dimatikan. Catatan: Jika file index.html dibuka langsung lewat File Manager HP (alamat file://), browser Android membatasi fitur cache offline PWA, namun seluruh fitur utama tetap berjalan.
